=== Post-install steps ===

1. PostgreSQL operator (required — not bundled):
   This chart does NOT deploy Postgres. Install the CloudNativePG operator first:

     helm repo add cnpg https://cloudnative-pg.github.io/charts
     helm upgrade --install cnpg cnpg/cloudnative-pg \
       --namespace cnpg-system --create-namespace

   Then create a Cluster resource and set DATABASE_URL in the secret.

2. Secrets (required if not pre-created):
   The chart renders a Secret only if you pass secret values at install time:

     helm upgrade --install registry \
       oci://ghcr.io/registry/helm/registry \
       --set secrets.databaseUrl="postgresql://user:pass@pgbouncer/catalog" \
       --set secrets.oidcDiscoveryUrl="https://accounts.example.com/.well-known/openid-configuration"

   For production, prefer External Secrets Operator or Vault Agent so secrets
   never transit Helm release history.

3. API endpoint:
   {{- if .Values.ingress.enabled }}
   Ingress is enabled. The API is reachable at:
     https://{{ (index .Values.ingress.hosts 0).host }}/v1
   {{- else }}
   Ingress is disabled. Port-forward to test:
     kubectl port-forward svc/{{ include "contextplane.fullname" . }} 8080:80
   Then: curl http://localhost:8080/healthz
   {{- end }}

4. /metrics now requires a bearer credential.
{{- if or ((.Values.metrics).auth).token ((.Values.metrics).auth).existingSecret }}
   A credential is configured. Verify the endpoint answers:
     kubectl port-forward svc/{{ include "contextplane.fullname" . }} 8080:80
     curl -H "Authorization: Bearer <token>" http://localhost:8080/metrics
{{- else }}
   ** NO CREDENTIAL IS CONFIGURED. /metrics returns 503 and this release is
   ** unmonitored until you set one. The endpoint publishes the route table,
   ** entitlement-failure counts, and per-tool MCP call counts, so it has no
   ** unauthenticated mode.

   Two ways to supply one:

     a) Chart-managed (simplest; the value transits Helm release history):
        --set metrics.auth.token="$(openssl rand -hex 32)"

     b) Operator-managed (preferred for production):
        kubectl create secret generic {{ include "contextplane.fullname" . }}-metrics \
          --from-literal=METRICS_BEARER_TOKEN="$(openssl rand -hex 32)"
        --set metrics.auth.existingSecret={{ include "contextplane.fullname" . }}-metrics
{{- end }}

   Existing scrape configurations must be updated to send the credential.
   Prometheus discovery annotations remain enabled, so a scraper without it
   reports this target DOWN with a 401 rather than vanishing from the target
   list — the failure is visible rather than silent.
{{- if ((.Values.metrics).serviceMonitor).enabled }}
   A ServiceMonitor is enabled and reads the credential from the Secret.
{{- end }}

5. Grafana dashboards:
   Copy helm/grafana-dashboards/ to your Grafana provisioning ConfigMap, or
   set grafana.dashboards.enabled=true if using the Grafana operator.
